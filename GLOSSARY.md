# Glossary

| Term | Means | Not to be confused with |
|---|---|---|
| Report | One zip with what-happened.txt, app.log, manifest.json and the optional screenshot and working file | A GitHub issue (the bug intake makes those from reports) |
| File Drop | The upload-only public share on the owner's Nextcloud that receives reports | The reporting user's own Files |
| Error buffer | The in-browser ring buffer of recent errors and warnings this module records | The server's nextcloud.log |
| Working file | The document the user had open (an outline, a project list), included only when the user ticks the box | The screenshot |
| Consent screen | The screen that lists every file before anything is sent | The form |
| Host app | A Craft web app that mounts this module (nc-outliner, nc-projects) | This module |
